# Real AI string breeder

This version uses a real language model from OpenAI instead of a pure random genetic algorithm. It still uses a score-based loop, but the candidate strings are generated by a real model that is told to suggest improved string variations based on the best previous guesses.

## Why this is different

A classic genetic algorithm uses random mutation and crossover to search for a target. A real model adds a different kind of intelligence: it reads the target and the best previous candidates, then tries to generate better guesses using language understanding.

So this version is a hybrid:

- a real AI model generates candidate strings
- a fitness score checks how close each candidate is to the target
- the best candidates are fed back into the model for another generation

## Requirements

```bash
pip install openai
```

Then set your API key:

```bash
export OPENAI_API_KEY=your_key_here
```

On Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="your_key_here"
```

## Run it

```bash
python real_ai_string_breeder.py
```

Example:

```bash
python real_ai_string_breeder.py
Enter the target string: HELLO WORLD
```

## Important note

This is not a model trained to "learn" your exact target from scratch. It is a general-purpose AI model being used as a generator for candidate strings. It is a real AI approach, but the actual optimization is still guided by a numeric fitness score.

The project also still contains the simpler educational genetic algorithm in `string_breeder.py` for learning the concept without needing an API key.
