How the “breeding” works

1. Score (selection)

Each guess earns a point for every character that matches the target at the same position. The percentage is its fitness.

2. Combine (crossover)

The two highest-scoring guesses become parents. Each child takes each character from one parent or the other.

3. Change (mutation)

Each character has the chosen chance to change randomly. Mutation adds variety so the guesses can explore new possibilities.

Important: This is a toy genetic algorithm, not a learning AI and not real biological crossbreeding. It can take a long time to find some targets; mutation and random chance affect how quickly it succeeds.
